# Security Policy

## NITM-SOSC — Responsible Disclosure

The security of our projects and the people who use them matters to us.

NITM-SOSC encourages responsible security research and appreciates contributions that help identify and address vulnerabilities in our open-source projects.

## Reporting a Vulnerability

If you discover a potential security vulnerability in an NITM-SOSC project, please report it responsibly.

**Please do not disclose security vulnerabilities through public GitHub Issues or Discussions.**

Instead:

1. Open the affected repository's **Security** tab.
2. Select **Report a vulnerability** if private vulnerability reporting is available.
3. Provide a clear description of the vulnerability and the affected component.
4. Include steps to reproduce the issue, potential impact and supporting evidence where possible.

If private vulnerability reporting is unavailable, contact the repository maintainers privately using the contact information provided in that project's README.

## What to Include

Please provide:

- Affected repository and component.
- Description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Relevant screenshots, logs or proof of concept, where appropriate.
- Suggested mitigation, if known.

## Our Response

Our maintainers will make reasonable efforts to:

- Acknowledge vulnerability reports.
- Assess the reported security issue.
- Coordinate investigation and remediation.
- Communicate with the reporter about relevant updates.
- Publish an appropriate security advisory when necessary.

Response and remediation timelines may vary depending on severity, complexity and maintainer availability.

## Responsible Disclosure Guidelines

We request security researchers to:

- Avoid accessing, modifying or deleting other people's data.
- Avoid disrupting services or degrading system availability.
- Never exploit vulnerabilities beyond what is necessary to demonstrate the issue.
- Respect user privacy and confidentiality.
- Allow maintainers reasonable time to investigate and address reported issues before public disclosure.

## Scope

This policy applies to repositories maintained under the NITM-SOSC GitHub organisation.

Individual projects may publish additional security requirements or supported-version policies.

## Thank You

Responsible security research strengthens open-source software and helps build a safer technology ecosystem.
